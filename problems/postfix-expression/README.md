# 后缀表达式求值

## 题目描述

四则运算表达式可以使用表达式树来表示。

对于一棵表达式树，其后序遍历顺序为：

> 先遍历左子树，再遍历右子树，最后访问根节点，即 **LRN**。

现给定一个字符串 `expression`，表示一个以后序遍历形式书写的四则运算表达式，请计算该表达式的结果。

表达式中只包含整数以及 `+`、`-`、`*`、`/` 四种双目运算符。

## 函数接口

```c
static int Calc(const char *expression)
{
    return 0;
}
```

请实现 `Calc` 函数并返回表达式的计算结果。

## 输入格式

输入为字符串 `expression`。

表达式由若干操作数和运算符组成，各个元素之间使用一个英文逗号 `,` 分隔。

例如：

```text
9,3,5,-,2,*,+
```

## 输出格式

返回一个整数，表示表达式的计算结果。

## 数据范围

- `1 <= expression.length < 50000`
- 操作数均为合法整数
- 运算符只包含 `+`、`-`、`*`、`/`
- 所有运算均为双目运算，不存在单目运算
- 中间计算结果范围为 `[-2^31, 2^31)`
- 最终结果范围为 `[-2147483648, 2147483647]`
- 测试用例保证表达式合法
- 测试用例保证一定存在计算结果
- 测试用例中不存在除数为 `0` 的情况

## 除法规则

整数除法只保留整数部分，并向 `0` 截断。

例如：

```text
5 / 4  = 1
-5 / 3 = -1
5 / -3 = -1
```

无需考虑余数。

---

## 示例 1

### 输入

```text
9,3,5,-,2,*,+
```

### 输出

```text
5
```

### 解释

后缀表达式的计算过程为：

```text
3 - 5 = -2
-2 * 2 = -4
9 + (-4) = 5
```

因此最终结果为：

```text
5
```

---

## 示例 2

### 输入

```text
3,-3,-,2,/,10,-
```

### 输出

```text
-7
```

### 解释

对应的中缀表达式为：

```text
(3 - (-3)) / 2 - 10
```

计算过程：

```text
3 - (-3) = 6
6 / 2 = 3
3 - 10 = -7
```

因此最终结果为：

```text
-7
```

## 解题要求

使用 **C 语言** 实现以下函数：

```c
static int Calc(const char *expression);
```

函数接收后缀表达式字符串，并返回其计算结果。
