# 收银台设计

请给某为无人便利店设计一个简易收银台系统，实现自动收银和找零。

1. 支持面额：1元、5元、10元、50元、100元。
2. 初始状态：收银台有一定数量的1元、5元、10元、50元面额的钞票用于找零，依次记录于数组initCashes中。
3. 收银台对付款请求 payments 逐笔进行收银，每笔收银 payments[i]= [price ,paidcash]\(price表示该账单价格，数组paidCashes表示本次所付 1 元、5 元、10 元、50 元、100 元面额钞票的数量)。收银策略如下
   付款小于price时，收银失败，并退回收到的钞票；
   收款等于price时，收银成功；
   付款大于price时，按“找零的钞票数量最少”的规则进行收钱和找零
   若能找零成功，收到的钞票计入收银台；
   若收银台零钱不足，则收银失败，并退回收到的钞票。
   请计算首映结束后，收银台剩余的的从小到大5个面额的钞票数量。

## 输入

第一个参数为initCashse,initCashes.length ==4, 0<=initCashes[i]<=1000;

第二个参数为payments,1<=payments.legth<=10000,

1<=price<=1000,paidCashse.length ==5,0<=paidCashes[i]<=1000

## 输出

一个长度为5的整数列表表示收银台剩余的从小到大5个面额的钞票数量

## 样例1

输入:[5,2,5,1]

[[47,[0,0,0,0,1]],[2,[0,1,0,0,0]],[1,[1,0,0,1,0]]]

输出: [3,2,5,0,1]
